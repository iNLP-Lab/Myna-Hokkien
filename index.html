The project

Hokkien remains under-supported in speech AI.

Hokkien is spoken across Asia and carries family life, humour, and everyday knowledge in Singapore. Yet it remains largely absent from mainstream speech interfaces. Myna-Hokkien is one open research attempt to address that gap.

One illustrative prompt

“How do I pronounce ‘happy birthday’?”

Myna-Hokkien

Teaches the user patiently how the word is pronounced in fluent Singapore Hokkien.

GPT Audio

Sounds robotic, garbled, and incoherent.

Qwen3.5-Omni

Repeats the question in Mandarin.

Gemini Live

Fails to help with tonality and is generally incoherent.

GLM-Voice

Answers in Mandarin incoherently.

Language and delivery labels reflect our listening to this selected run. It is an illustrative example, not a benchmark or a general evaluation of these systems.

How it works

One native model, speech to speech.

Base architecture
Qwen3-Omni-30B-A3B-Instruct
Weights
Approximately 70.5 GB · BF16 / FP16
Language
Singapore Hokkien / Minnan · nan
Voice
Ethan · single voice in this release
Input / output
16 kHz mono audio or text in; text and 24 kHz mono audio out
Primary task
Spoken question answering

Run it

Install, then ask a spoken question.

Weights, runtime, and full documentation are on Hugging Face ↗.

# Install
pip install --upgrade huggingface_hub
MODEL_DIR="$(hf download iNLP-Lab/MynaHokkien --quiet)"
pip install "$MODEL_DIR"
import torch
import soundfile as sf
from mynahokkien import MynaHokkien

model = MynaHokkien.from_pretrained(
    "iNLP-Lab/MynaHokkien",
    device_map="cuda:0",
    dtype=torch.float16,
)

output = model.generate(
    audio="question.wav",
    language="nan",
    return_text=True,
    return_audio=True,
)

print(output.text)
sf.write("output.wav", output.audio, output.sampling_rate)

Supply exactly one of audio= or text=. If prompt= is omitted, the release runtime applies its built-in instruction requesting a concise Singapore-Hokkien reply written in Hanji. The prompt is an instruction, not a hard decoding guarantee.

Next steps

Improve the model, then evaluate it more broadly.

  • Lighter checkpoints to support experiments on more modest hardware.
  • Broader tasks beyond the current spoken question-answering focus.
  • Broader Chinese dialect coverage to include more Chinese dialect varieties in the future.
  • Community evaluation with Hokkien speakers across different ages and backgrounds.
  • More expressive data to study speaking style and emotional range.
