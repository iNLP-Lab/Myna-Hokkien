The project

Hokkien remains under-supported in speech AI.

Hokkien is spoken across Asia and carries family life, humour, and everyday knowledge in Singapore. Yet it remains largely absent from mainstream speech AI models. Myna-Hokkien is one open research project addressing that gap.

The example below shows how Myna-Hokkien and four general-purpose speech models respond to the same spoken Hokkien request.

One illustrative prompt

“My mood is very low today.”

Myna-Hokkien

Responds with concern in fluent Singapore Hokkien.

GPT Audio

Fails to answer the question.

Qwen3.5-Omni

Responds in Mandarin without answering the question.

Gemini Live

Unnatural speech and pacing; somewhat garbled.

GLM-Voice

Refuses in English.

01

Birthday pronunciation

Model input · Hokkien audio

What is said, in English

“How do I pronounce ‘happy birthday’?”

Myna-Hokkien output · audio + transcript

Output transcript

哎哟，生日就是“生日”啦，毋是“生利”。

02

How do you say AI?

Model input · Hokkien audio

What is said, in English

“People are talking about AI these days. What is it called in Hokkien?”

Myna-Hokkien output · audio + transcript

Output transcript

哎哟，这问题真趣味！咱福建话通常拢讲“AI”（发音像“爱”），或者是讲“人工智慧”。

Rough English meaning

Oh, what an interesting question! In Hokkien, we usually say “AI” (pronounced like “love” in Mandarin), or “artificial intelligence.”

How it works

One native model, speech to speech.

Base architecture
Qwen3-Omni-30B-A3B-Instruct
Weights
35B total parameters · 3B active
Language
Singapore Hokkien / Minnan · nan
Voice
Ethan · single voice in this release
Input / output
16 kHz mono audio or text in; text and 24 kHz mono audio out
Primary task
Spoken question answering

Run it

Install, then ask a spoken question.

Weights, runtime, and full documentation are on Hugging Face ↗.

# Install
pip install --upgrade huggingface_hub
MODEL_DIR="$(hf download iNLP-Lab/Myna-Hokkien --quiet)"
pip install "$MODEL_DIR"
import torch
import soundfile as sf
from mynahokkien import MynaHokkien

model = MynaHokkien.from_pretrained(
    "iNLP-Lab/Myna-Hokkien",
    device_map="cuda:0",
    dtype=torch.float16,
)

output = model.generate(
    audio="question.wav",
    language="nan",
    return_text=True,
    return_audio=True,
)

print(output.text)
sf.write("output.wav", output.audio, output.sampling_rate)

Supply exactly one of audio= or text=. If prompt= is omitted, the release runtime applies its built-in instruction requesting a concise Singapore-Hokkien reply written in Hanji. The prompt is an instruction, not a hard decoding guarantee.
